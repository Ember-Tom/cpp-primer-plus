8.1内联函数
内联函数：C++区别于C的新增特性。
使用方法：定义和声明函数时在函数前添写 inline 
使用示例：inline double square(double x) { return x * x; }
使用须知：如果执行函数代码的时间比处理函数调用机制的时间长，则节省的时间将只占整个过程的很小一部分。如果代码执行时间很短，则内联调用就可以节省非内联调用使用的大部分时间。另一方面，由于这个过程相当快，因此尽管节省了该过程的大部分时间，但节省的时间绝对值并不大，除非该函数经常被调用。

内联与宏定义：内联函数效果类似于C语言的宏定义但优于宏定义。普通函数调用时，是跳转到该函数的地址，然后执行相关语句，最后再跳回原处继续工作。相当于看书看到某个词语有注释的时候翻书去看注释，看完后再返回来接着看下面的内容。inline工具是C++新增的特性。C语言使用预处理器语句#define来提供宏——内联代码的原始实现。例如，下面是一个计算平方的宏：
#define SQUARE(X) X*X
这并不是通过传递参数实现的，而是通过文本替换来实现的——X是“参数”的符号标记。
a = SQUARE(5.0); is replaced by a = 5.0*5.0;
b = SQUARE(4.5 + 7.5); is replaced by b = 4.5 + 7.5 * 4.5 + 7.5;
d = SQUARE(c++); is replaced by d = c++*c++;
上述示例只有第一个能正常工作。可以通过使用括号来进行改进：
#define SQUARE(X) ((X)*(X))
但仍然存在这样的问题，即宏不能按值传递。即使使用新的定义，SQUARE（C++）仍将c递增两次，但是程序清单8.1中的内联函数square( )计算c的结果，传递它，以计算其平方值，然后将c递增一次。这里的目的不是演示如何编写C宏，而是要指出，如果使用C语言的宏执行了类似函数的功能，应考虑将它们转换为C++内联函数。

注意事项：程序员请求将函数作为内联函数时，编译器并不一定会满足这种要求。它可能认为该函数过大或注意到函数调用了自己（内联函数不能递归），因此不将其作为内联函数；而有些编译器没有启用或实现这种特性。

8.2引用变量
引用变量：C++新增了一种复合类型——引用变量。引用是已定义的变量的别名（另一个名称）。例如：齐天大圣与孙悟空的关系。
使用方法：C++给&符号赋予了另一个含义，将其用来声明引用。
使用示例：
int rats = 101;
int &rodents = rats;
引用与指针：
1、引用必须在声明时初始化被引用的变量，否则无法编译。指针可以先声明再赋值。
2、引用与指针不同，引用十分专一，只会与初始化设定的变量的地址相同，且后续无法改变。指针除非被const束缚，否则会指向任何变量的地址。（引用更接近const指针，必须在创建时进行初始化，一旦与某个变量关联起来，就将一直效忠于它。）

异或运算符 ^ 
可实现两数数值的高效交换，无额外内存开销（仅限整数类型）；
如交换 num1 与 num2 的值；
int num1 = 5, num2 = 6;
num1 = num1 ^ num2; // 0000 0101 ^ 0000 0110 = 0000 0011 /* 3 */
num2 = num1 ^ num2; // 0000 0011 ^ 0000 0110 = 0000 0101 /* 5 */
num1 = num1 ^ num2; // 0000 0011 ^ 0000 0101 = 0000 0110 /* 6 */
a ^ b ^ a = b（推导：(a ^ a) ^ b = 0 ^ b = b）
